# TEKMOVELA Python SDK (skeleton)

Planned surface for the M1 Verification Kernel:

- `tekmovela.contracts` — load and validate contract fixtures.
- `tekmovela.harness` — author Runner/Adapter/Oracle/Reporter components.
- `tekmovela.runner` — local deterministic runner.
- `tekmovela.evidence` — emit digest-verifiable EvidenceBundle records.

Nothing is implemented yet; the package metadata is in place.
