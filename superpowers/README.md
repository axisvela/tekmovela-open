# TEKMOVELA Open Superpowers Harness

OpenCode loads Superpowers from the upstream plugin declared in `../opencode.json`.

This directory is reserved for TEKMOVELA Open-specific harness material such as SDK development workflows and integration examples. Do not place public-facing product documentation here; that lives in `docs/`.

Public integration rules are in `AGENTS.md`. This repository is the public face of TEKMOVELA (Apache 2.0); core planning lives in the private core and EE repositories.
